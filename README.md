## 🌟 核心文档结构

本项目专为 **Google Antigravity 2.0** 与 **Antigravity CLI (`agy`)** 打造，纯粹聚焦于**工程纪律规范与子 Agent 角色分工**：

1. **📄 [AGENTS.md](AGENTS.md)**：工作区核心工程纪律规范（产品思维先行、防幻觉、两击熔断、Ponytail 最小正确改动、TDD 强制验证等 0~9 大纪律）。
2. **🤖 [SUBAGENTS.md](SUBAGENTS.md)**：独立的 Subagent 角色分工与派发手册（执行轨 Builder 与审查轨 Adversary 双轨隔离、只读沙盒与 Git 分支隔离规范）。

## ⚡ 快速接入

在任何工程根目录下直接拉取：

```bash
# 1. 下载核心工程规范 AGENTS.md
curl -sSL https://raw.githubusercontent.com/Alphaxiaoteng/antigravity-agent-guidelines/main/AGENTS.md -o AGENTS.md

# 2. 下载子 Agent 分工手册 SUBAGENTS.md
curl -sSL https://raw.githubusercontent.com/Alphaxiaoteng/antigravity-agent-guidelines/main/SUBAGENTS.md -o SUBAGENTS.md
```
